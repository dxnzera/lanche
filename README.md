# 🍔 Lanchê Landing Page

React Vite TailwindCSS Motion

Landing page moderna e responsiva desenvolvida para a marca Lanchê, focada em experiência visual, performance e organização escalável do código.

---

# Sobre o Projeto | About the Project

A Lanchê Landing Page foi construída com foco em performance, design moderno e fácil manutenção. O projeto utiliza React com Vite para uma experiência rápida de desenvolvimento, além de uma arquitetura organizada para facilitar escalabilidade e versionamento.

The Lanchê Landing Page was built focusing on performance, modern UI, and maintainable architecture. The project uses React with Vite for a fast development experience and a scalable code structure.

# Estrutura do Projeto | Project Structure

```txt
src/
│
├── app/
│   ├── App.tsx
│   │
│   ├── components/
│   │   ├── landing/
│   │   └── ui/
│   │
│   ├── models/
│   │
│   └── data/
│
├── assets/
│
└── main.tsx
```

### Estrutura

* `src/app/App.tsx` → composição principal da landing
* `src/app/components/landing` → seções e blocos da experiência
* `src/app/components/ui` → componentes reutilizáveis
* `src/app/models` → modelos e regras leves de apresentação
* `src/app/data` → conteúdo centralizado
* `src/assets` → imagens e assets da marca

# Desenvolvimento Local | Local Development

## Pré-requisitos | Requirements

* Node.js 18+
* npm ou yarn

## Passos | Steps

Clone o repositório:

```bash
git clone https://github.com/seuusuario/lanche-landing-page.git
```

Entre na pasta:

```bash
cd lanche-landing-page
```

Instale as dependências:

```bash
npm install
```

Execute o projeto:

```bash
npm run dev
```

Abra no navegador:

```txt
http://localhost:5175
```

O servidor Vite está configurado para responder em `0.0.0.0`, facilitando ambientes remotos e port forwarding.
